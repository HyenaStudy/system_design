# Chapter 5 안정 해시 설계

### 1. 해시 키 rehash 문제

- N개의 캐시 서버가 존재할 때, 각 서버들이 부하를 균등하게 짊어질 수 있도록 해시 함수를 통해 캐시를 배치 한다.
    
    severIndex = hash(key) % N
    
    → 4개의 캐시 서버가 있다면 나머지 연산의 결과 값으로 접속할 서버를 조회한다.
    
- 데이터 분포가 균등하거나 서버의 개수가 고정적이면 문제가 없지만 서버의 수가 변하면 장애 발생 위험이 높아진다. → 대규모 캐시 미스로 이어지고 db 부하로 이어진다

### 2. 안정 해시

- 해시 케이블 크기가 조정될 때 오직 k(키의 개수)/n(슬롯의 개수)개의 키만 재배치 하는 해시 기술

**해시 공간**

- 해시 함수는 임의의 값을 넣으면 정해진 범위 내에서 숫자를 반환
- 반환 가능한 전체 숫자의 범위를 해시 공간이라고 함

**해시링**

- 해시 공간을 원형으로 연결하면 해시링
- 키를 특정 노드에 배정할 때 해시링으로 구성하여 시계 방향으로 가장 가까운 노드를 선택하는 방법 활용 가능
- 서버가 추가 되거나 제거될 때 안정적임 → rehash가 적게 발생하여 안정적
- 기존 해시의 경우 4대에서 3대로 줄 경우 거의 대부분의 캐시를 재배치해야함
- 해시 링의 경우 1 → 2 → 3에서 4대로 늘었을 경우 3의 일부만 4로 할당해주면 된다.
- 파티션의 크기를 균등하게 유지 불가능하다는 단점 존재

**가상 노드**

- 해시링에서 키를 더 균등하게 분배하기 위해 사용
- 해시 링 위에서 서버를 여러 위치에 흩어져 배치하도록 함

### 3. 사용 사례

**디스코드**

> After doing some research, we found mochiglobal, a module that exploits a feature of the VM: if Erlang sees a function that always returns the same constant data, it puts that data into a read-only shared heap that processes can access without copying the data. mochiglobal takes advantage of this by creating an Erlang module with one function at runtime and compiling it. Since the data is never copied, the lookup cost decreases to 0.3us, bringing the total time down to 750ms! There’s no such thing as a free lunch though; the cost of building a module with a data structure as large as the ring at runtime can take up to a second. The good news is that we rarely change the ring, so it was a penalty we were willing to take.
> 
1. 디스코드는 서버와 사용자가 많아서 각 서버와 사용자를 담당할 서버를 해시링을 통해 분배하였음
2. 동시 사용자수가 늘어나면서 사용자 접속, 메시지 전송 마다 해시링을 조회하여 부하 발생
(해시링의 결과 값을 반환해주는 프로세스는 단 하나로 존재하여 병목 발생)
3. 해시링을 통채로 읽기 전용 캐시로 올려 조회 속도를 향상함
    - 데이터를 통채로 공유 캐시에 올려두고 모든 프로세스가 그 데이터에 대해 같은 포인터를 바라보게 함
    - 해시링을 처리하는 프로세스가 하나일때는 응답받을 때까지 대기해야 해서 병목 발생
    - 캐시의 경우 메모리를 조회하면  끝남
    - 메모리 복사 없이 참조만 하여 찾아감 (변경 주기가 굉장히 낮음) → 수정된 경우에만 해시링을 새로 생성하고 완성된 순간 모든 캐시 교체
4. ETS (Erlang Term Storage)
    - 직접 데이터를 read해옴
    - 데이터 복사 비용 존재 (참조 공유 x)

```java
import org.openjdk.jmh.annotations.*;
import org.openjdk.jmh.infra.Blackhole;

import java.util.Random;
import java.util.concurrent.ArrayBlockingQueue;
import java.util.concurrent.BlockingQueue;
import java.util.concurrent.ThreadLocalRandom;
import java.util.concurrent.TimeUnit;

@BenchmarkMode(Mode.AverageTime)
@OutputTimeUnit(TimeUnit.NANOSECONDS)
@Warmup(iterations = 3, time = 1)
@Measurement(iterations = 5, time = 1)
@Fork(1)
@Threads(8)
@State(Scope.Benchmark)
public class HashRingBenchmark {

    @Param({"100000"})
    int ringSize;

    int[] ring;

    BlockingQueue<Integer> reqQ;
    BlockingQueue<Integer> resQ;
    Thread ipcServerThread;
    volatile boolean running;

    interface ETSStyle { int get(int idx); }

    static class LockBasedETS implements ETSStyle {
        private final int[] ring;
        LockBasedETS(int[] r) { this.ring = r; }
        @Override public synchronized int get(int idx) { return ring[idx]; }
    }

    ETSStyle ets;

    @Setup(Level.Trial)
    public void setup() {
        ring = new int[ringSize];
        Random r = new Random(0);
        for(int i=0;i<ringSize;i++) ring[i] = r.nextInt();

        reqQ = new ArrayBlockingQueue<>(1024);
        resQ = new ArrayBlockingQueue<>(1024);
        running = true;
        ipcServerThread = new Thread(this::ipcLoop);
        ipcServerThread.start();

        ets = new LockBasedETS(ring);
    }

    private void ipcLoop() {
        try {
            while (running) {
                int idx = reqQ.take();
                if(idx == -1) break;
                resQ.put(ring[idx]);
            }
        } catch (Exception ignored) {}
    }

    @TearDown(Level.Trial)
    public void stop() throws Exception {
        running = false;
        reqQ.put(-1);
        ipcServerThread.join();
    }

    @Benchmark
    public void ipc(Blackhole bh) throws Exception {
        int idx = ThreadLocalRandom.current().nextInt(ringSize);
        reqQ.put(idx);
        bh.consume(resQ.take());
    }

    @Benchmark
    public void ets(Blackhole bh) {
        int idx = ThreadLocalRandom.current().nextInt(ringSize);
        bh.consume(ets.get(idx));
    }

    @Benchmark
    public void shared_heap(Blackhole bh) {
        int idx = ThreadLocalRandom.current().nextInt(ringSize);
        bh.consume(ring[idx]);
    }
}
```
